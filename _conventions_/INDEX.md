# `_conventions_`

Instance of this project's `_conventions_` type: **convention articles — agent-maintainable**. The rules are
kept here so they can be cited, diffed and judged; a rule that lives only in one session's memory is a rule
that gets forgotten.

This folder holds Heddle's **own** conventions. The conventions borrowed from the wider
`reflection` repository — entry points, frontmatter, commit messages, change tracking, DSH-and-DRY,
durable work, browser modes — are stated there and are linked from [`../AGENTS.md`](../AGENTS.md); they are
not copied here, because one fact in one place is itself one of them.

| Instance | What it decides |
|---|---|
| [`heddle-conventions/`](heddle-conventions/INDEX.md) | the rules that are specific to Heddle: how its state is tracked, what may resume, and how those rules are judged |

A convention here is **agent-maintainable**: an agent may propose and land an article, with its reasoning and
the verifier that judges it. (The mirror-image type, `_constitutions_`, is human-only to amend — nothing in
this folder carries that weight.)
